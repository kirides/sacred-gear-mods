## v0.2.0 (2026-11-15)

- New: An edit mode lets you drag game windows and mod panels; each one gets a blue frame.
- New: Frames snap to screen edges and to other frames; hold Shift to place freely.
- New: Select a frame and nudge it with the arrow keys, or set its place in a popup.
- New: Resizable mod panels change size by their corner or in the popup.
- New: Places are kept when the screen resolution changes.
