## v0.2.3 (2026-11-24)

- Fixed: A frame hanging over the screen edge now has its name centred on the visible part.

## v0.2.2 (2026-11-23)

- Fixed: Hidden windows, closed panels and the save/load window no longer show in edit mode.

## v0.2.1 (2026-11-19)

- Improved: Edit layout is now a button in the top left, shown while Alt is held.
- Improved: The layout editor no longer uses F7; Done ends the edit mode.
- New: Controller users can open Edit layout from the mod menu and move frames with the pad.
- Improved: Arrow keys repeat at an even pace, so a short press moves a frame only once.

## v0.2.0 (2026-11-15)

- New: Edit mode (F7) lets you drag game windows and mod panels; each gets a blue frame.
- New: Frames snap to screen edges and to other frames; hold Shift to place freely.
- New: Select a frame and nudge it with the arrow keys, or set its place in a popup.
- New: Resizable mod panels change size by their corner or in the popup.
- New: Reset windows or everything back to their places from the edit toolbar.
- New: Places are kept when the screen resolution changes.

## v0.1.0 (2026-11-15)

- First release: move the game's windows and mod panels anywhere on screen, in an edit mode.
