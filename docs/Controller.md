# Controller

Sacred Gear's mod UI works with Xbox, PlayStation and Switch pads (read through SacredBild). The details are in
sacred-bild's [Controller](https://github.com/kirides/sacred-bild/blob/main/docs/Controller.md#sacred-gear-mods) page;
what matters for the mods here:

- **Mod menu**: **LT + LB** lists what the mods offer as buttons: the Mods screen, every hotkey a mod declares (Autosave
  now, the loot filter settings) and tools like *Edit layout*. **A** runs one, **B** closes the menu.
- **Mods screen** (and the mod menu): takes the pad alone while open. The D-pad moves among its buttons, sliders and
  check boxes (D-pad left / right changes a slider), **A** clicks, **B** steps back. Text settings and key binds have a
  **Kbd** / **Pick** button for an on-screen keyboard or a key list.
- **Shared stash**: a mod window with an X; the pad switches to the cursor as it does for a game window. The left stick
  moves the cursor, **A** clicks, **B** closes the top window. The *Shared stash* button next to the chest is a mod
  panel as well.
- **Autosave** needs nothing; start *Autosave now* from the mod menu for a save on demand.
